# Ronak Creations — Gift Shop Website

Website for Ronak Creations, a gift shop in Numaish Camp, Saharanpur.

Built with Next.js 16 + Tailwind CSS. Hosted on Vercel.

## Commands

```bash
npm run dev      # dev server
npm run build    # production build
npm run start    # serve production build
npm run lint     # run ESLint
```

## Pages

- `/` — Home, featured products, highlights
- `/products` — Full product catalog
- `/customize` — Custom gift hampers
- `/about` — About the shop
- `/contact` — Location, WhatsApp, Instagram, map
